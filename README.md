# R Data Analysis

Os exemplos estão em `Versão R-Studio` e `Versão Jupyter`. Use o RStudio ou o Jupyter com IRkernel e execute os exemplos a partir da raiz do clone ou da pasta da atividade.

As bases incluídas ficam em `Doc`. Para usar outra pasta, defina `EXEMPLOS_R_DADOS` antes de executar. Os exercícios de ordenação, substituição e agrupamento usam amostras fictícias quando as planilhas correspondentes estão ausentes.
